# Telegram Tic-Tac-Toe Bot

Небольшой Telegram-бот на Python и aiogram 3, который играет с пользователем в крестики-нолики.

## Сценарий

1. Пользователь пишет боту любое сообщение или /start.
2. Бот предлагает начать игру.
3. Пользователь нажимает «🎮 Начать игру».
4. Пользователь делает ходы кнопками на игровом поле.
5. Бот отвечает оптимальным ходом.
6. После победы, поражения или ничьей бот предлагает начать новую игру.

## Запуск

1. Создай бота через @BotFather и получи токен.
2. Создай виртуальное окружение.
3. Установи зависимости командой: pip install -r requirements.txt
4. Скопируй .env.example в .env и укажи BOT_TOKEN.
5. Запусти командой: python -m bot.main

## Тесты

Запусти pytest.

Игровая логика отделена от Telegram-слоя и покрыта базовыми тестами.
